The Workspace

This is where you solve. We've packed it with tools to simulate a real environment.

Timer Controls

  • Start: Begins the count-up timer. Always time yourself.
  • Pause: Pauses the timer if you need a break.
  • Reset: Sets timer back to 00:00:00.

Helpers

  • Starter Code: Opens the boilerplate Java code for this problem.
  • Hints: Shows progressive hints without revealing the full answer.
  • Solution: Opens the optimal solution code.

Personal Notes

  • Edit Mode: Click the pencil icon to start writing. Supports Markdown (*bold*, lists, code).
  • Save: Persists your notes to your browser's local storage.
